## 2. Regression และบั๊กใหม่

- ไม่พบบั๊กใหม่ เคสเดิมทั้งหมดผ่าน: เฉลย/รหัสความเข้าใจผิด 123 คู่, ขั้นแนะนำทั้ง 9 แถว, หยุดกลางทาง, ข้ามด่าน 5, event 22 ตัว, จังหวะแฟลช, ไม่มีเวลา/คะแนน/ถูกผิด
- ผลข้างเคียงของ tap-guard ที่ตรวจแล้วไม่พบปัญหา: เวลาเงียบไม่เปลี่ยน (ความหน่วงตรงกับที่เดินจริง ±2 ms ทุกข้อ ใน TC-20), ข้อที่ตอบหลังแตะที่เปลี่ยนหน้าต้อง ≥ 450 ms จึงตอบได้เร็วสุดประมาณนั้น (ไม่กระทบเกณฑ์คล่องที่ต่ำสุด 3 วินาที)
- ข้อสังเกต (ไม่ใช่บั๊ก): tap-guard ทำให้เด็กที่ตอบข้อถัดไปเร็วกว่า 400 ms หลังแตะเลือกวิธีคิด/ไปเลย จะถูกทิ้งการแตะโดยไม่มีสัญญาณ ตรงตาม §3.3.1
