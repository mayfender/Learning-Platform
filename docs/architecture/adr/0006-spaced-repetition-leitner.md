# ADR-0006: ระบบทบทวนเว้นระยะแบบกล่อง Leitner ที่ Designer ปรับค่าได้

- สถานะ: ยอมรับ (2026-09-30: Designer กำหนดช่วงเวลาและเกณฑ์ใน Lesson Spec ADD-04 §6.1–6.2 และเจ้าของโปรเจกต์อนุมัติแล้ว)
- วันที่: 2026-09-29 (แก้ไข 2026-09-30)

## บริบท
ต้องคำนวณว่าวันนี้ควรทบทวนทักษะไหน (F8) จาก event log (ADR-0003) ให้ Designer เข้าใจและปรับได้ และไม่กดดันเรื่องเวลา

## ทางเลือก
| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| **Leitner (กล่องเลื่อนขั้น)** | เข้าใจง่าย อธิบายให้พ่อฟังได้ ปรับช่วงเวลาได้ตรงๆ | ปรับตามตัวบุคคลได้น้อยกว่า |
| SM-2 / FSRS | แม่นกว่าเมื่อมีข้อมูลมาก | ซับซ้อน และข้อมูลเด็กคนเดียวน้อยเกินจะได้ประโยชน์ |

## การตัดสินใจ
ใช้ **Leitner ระดับทักษะ** (ไม่ใช่ระดับโจทย์)
- แต่ละทักษะมีกล่อง 1–5 และแต่ละกล่องมีช่วงทบทวน: **1, 2, 4, 7, 14 วัน** (ค่าที่ Designer กำหนดใน ADD-04 §6.2)
- ทักษะเข้าระบบทบทวนที่ **กล่อง 1** เมื่อส่วนของบทที่สอนทักษะนั้นผ่าน (รวมผ่านแบบ "กำลังไปได้ดี") กำหนดครั้งแรก = วันที่ผ่าน + ช่วงของกล่อง 1
- จบรอบทบทวนแล้ว "คล่อง" ตามเกณฑ์ของทักษะนั้น (ความถูกต้อง + เวลาเงียบ): เลื่อนขึ้น 1 กล่อง
- ไม่คล่อง (และไม่ใช่ความเข้าใจผิดกลุ่มรีเซ็ต): ถอยลง 1 กล่อง (ต่ำสุดกล่อง 1)
- ผิดตามความเข้าใจผิดกลุ่มรีเซ็ต (ADD-04: L1, M4, M6, M7): กลับกล่อง 1 และแจ้งพ่อ ส่วน M5 และ MX ไม่รีเซ็ต
- **เกณฑ์เวลามี 2 ระดับ ขึ้นกับกล่อง:** "ไม่ต้องนับ" ใช้กับกล่อง 1–2, "อัตโนมัติ" ใช้กับกล่อง 3–5 ค่ามิลลิวินาทีของแต่ละทักษะอยู่ใน `skills.ts`
- เกณฑ์ "คล่อง" ของรอบ: ถูก ≥ 3 จาก 4 ข้อ และเวลาอยู่ในระดับที่กำหนดตามกล่อง (ตัวเลขและการตีความข้อกำกวมดู Tech Spec ADD-04 §5.6)
- **ช่วงเวลา เกณฑ์ และกลุ่มความเข้าใจผิดอยู่ใน `src/content/skills.ts`** ให้ Designer แก้ได้โดยไม่แตะ engine (`engine/leitner.ts` รับ config เป็นพารามิเตอร์)
- คำนวณสถานะจาก event log ทั้งหมดทุกครั้ง (pure function) จึงเปลี่ยนกติกาย้อนหลังได้ วันครบกำหนดนับตามวันที่ในเวลาท้องถิ่น (ทำรอบตอนเย็น ครบกำหนดตั้งแต่เช้าวันถัดไป)

## ผลที่ตามมา
- Designer ต้องกำหนดเกณฑ์ "คล่อง" ของแต่ละทักษะใน Lesson Spec (ทำแล้วสำหรับ `add.bonds-10` และ `add.make-10`)
- event ที่ใช้คำนวณ: `block.completed` (ชนิด `review`) และ `item.answered` ของรอบนั้น (ดู ADR-0008 และ Tech Spec ADD-04 §6)
- DX-ADD ไม่ใช้ Leitner ผล DX-ADD ไม่ทำให้ทักษะเข้าระบบทบทวน
