# ADR-0006: ระบบทบทวนเว้นระยะแบบกล่อง Leitner ที่ Designer ปรับค่าได้

- สถานะ: เสนอ (รอ Learning Designer กำหนดช่วงเวลาและเกณฑ์)
- วันที่: 2026-09-29

## บริบท
ต้องคำนวณว่าวันนี้ควรทบทวนทักษะไหน (F8) จาก event log (ADR-0003) ให้ Designer เข้าใจและปรับได้ และไม่กดดันเรื่องเวลา

## ทางเลือก
| ทางเลือก | ข้อดี | ข้อเสีย |
|---|---|---|
| **Leitner (กล่องเลื่อนขั้น)** | เข้าใจง่าย อธิบายให้พ่อฟังได้ ปรับช่วงเวลาได้ตรงๆ | ปรับตามตัวบุคคลได้น้อยกว่า |
| SM-2 / FSRS | แม่นกว่าเมื่อมีข้อมูลมาก | ซับซ้อน และข้อมูลเด็กคนเดียวน้อยเกินจะได้ประโยชน์ |

## การตัดสินใจ
ใช้ **Leitner ระดับทักษะ** (ไม่ใช่ระดับโจทย์)
- แต่ละทักษะมีกล่อง 1–5 และแต่ละกล่องมีช่วงทบทวน (ค่าเริ่มต้นเสนอ: 1, 2, 4, 7, 14 วัน)
- จบรอบทบทวนแล้ว "คล่อง" ตามเกณฑ์ของทักษะนั้น (ความถูกต้อง + เวลาเงียบ): เลื่อนขึ้น 1 กล่อง
- ไม่คล่อง: ถอยลง 1 กล่อง / ผิดจากความเข้าใจผิด: กลับกล่อง 1 และแจ้งพ่อ
- ช่วงเวลาและเกณฑ์อยู่ใน `src/content/skills.ts` ให้ Designer แก้ได้โดยไม่แตะ engine
- คำนวณสถานะจาก event log ทั้งหมดทุกครั้ง (pure function) จึงเปลี่ยนกติกาย้อนหลังได้

## ผลที่ตามมา
- Designer ต้องกำหนดเกณฑ์ "คล่อง" ของแต่ละทักษะใน Lesson Spec
- ยังไม่ต้องสร้างใน DX-ADD (แบบทดสอบวินิจฉัย) แต่ event ที่บันทึกต้องมีข้อมูลพอให้ใช้ภายหลัง
